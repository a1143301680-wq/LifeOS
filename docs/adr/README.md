# Architecture Decision Records

Use this directory for durable LifeOS technical decisions.

Keep ADRs short and focused. Prefer one decision per file.

## Filename Format

```text
YYYYMMDD-short-decision-title.md
```

Example:

```text
20260710-phase1a-token-hash.md
```

## ADR Template

```text
# Title

Date: YYYY-MM-DD

## Status

Accepted | Proposed | Superseded

## Context

What problem or tradeoff forced this decision?

## Decision

What did we decide?

## Consequences

What becomes easier, harder, or constrained because of this?

## References

- Related docs or files
```
